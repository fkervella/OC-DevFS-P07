# Frontend Abricot

Cette base de code est le front end du projet Abricot. Elle permet de se connecter au [backend] (https://github.com/OpenClassrooms-Student-Center/dev-react-P10)

## Installation et Démarrage

1. Installer les dépendances :

```bash
npm install
```

2. Lancer le backend (voir la documentation associée)

3. Démarrer le serveur :

```bash
npm run dev
```

Le serveur démarre sur `http://localhost:3000`

Les utilisateurs par défaut dans le seed de la base de données sont indiqués dans la documentation du backend
